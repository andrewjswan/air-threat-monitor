# Notices and attribution

## NEPTUN data

Air-threat and air-alert data used by this project is provided by:

[Data: Air Alert Map - NEPTUN](https://neptun.in.ua/)

API documentation: <https://neptun.in.ua/developers>

API terms: <https://neptun.in.ua/api-terms>

The integration reads only documented public endpoints. It does not use the
NEPTUN logo, copy the NEPTUN interface, proxy the API, or present itself as an
official NEPTUN product. Every bundled card keeps a visible link identifying
NEPTUN as the data source.

## Safety disclaimer

NEPTUN and this integration are informational tools, not official warning
systems. Data can be delayed, incomplete, or inaccurate. Users must rely on
official air-alert signals and instructions from Ukrainian authorities for
safety decisions.

## Location privacy

Home coordinates are used locally to calculate distance and bearing. They are
not included in requests to the data provider.
